# Power BI Dashboard

## Overview

This Power BI dashboard is part of the Business Optimization Dashboard project. It analyzes inventory and business performance data using interactive visualizations.

## Tools Used

- Power BI
- SQL
- Power Query
- DAX

## Dashboard Analysis

- Demand and availability analysis
- Inventory performance
- Product-level analysis
- Business KPIs
- Demand vs availability
- Inventory shortage analysis
